# Branding Policy

Nico Rohrbach / Superpixel reserves all rights to the Tearoff icon and 
artworks (the "Marks"). The Marks are not covered by the MIT License 
applied to this repository's source code.

## What you MAY do without separate permission
- Refer to this project by name in blog posts, documentation, or articles
  to describe or link to it (nominative/descriptive use).
- State that your software "is built on" or "is a fork of" Tearoff,
  provided this does not imply endorsement or official status.

## What you MAY NOT do without written permission
- Use the Tearoff icon and artworks in your own product, fork, or
  distribution in a way that suggests it is the official version.
- Use a confusingly similar icon or artwork for a derivative project.
- Use the Marks in a way that implies sponsorship or endorsement by
  Nico Rohrbach / Superpixel.

## Forks and derivative builds
If you fork or rebuild this software, you must:
1. Remove the Tearoff icon and artworks from the build, and
2. Replace them with your own branding, or use clearly distinct
   placeholder branding.

This mirrors the approach taken by projects such as VS Code / VSCodium,
where the underlying code is open source (MIT) but the official product
name, icon, and branding remain proprietary and are stripped out in
community rebuilds.
